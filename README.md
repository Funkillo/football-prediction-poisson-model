# ⚽ Predicción Estadística de Fútbol: Modelo de Poisson

Este proyecto utiliza la **Distribución de Poisson** y **Simulaciones de Montecarlo** (100.000 iteraciones) para predecir resultados de partidos de fútbol basándose en datos históricos de rendimiento ofensivo y defensivo.

### 📋 Características
- **Cálculo de xG (Goles Esperados):** Basado en la fuerza de ataque y debilidad defensiva de los equipos.
- **Simulación 1X2:** Probabilidad porcentual de victoria local, empate o visitante.
- **Top Resultados:** Identificación de los 5 marcadores exactos más probables.
- **Análisis de Goleadores:** Probabilidad individual de marcar según el peso ofensivo en el equipo.

### 🚀 Cómo usarlo
1. Clona el repositorio.
2. Abre el archivo `.py` (Python) o `.R` (RStudio).
3. Localiza la sección de **Ingreso de Datos**.
4. Actualiza las variables (goles a favor/contra, partidos jugados) con los datos actuales de **Marca** u otras fuentes oficiales.
5. Ejecuta el script para generar el informe y la infografía automática.

### 📊 Tecnologías utilizadas
- **Python:** Pandas, Numpy, Matplotlib, Seaborn, Scipy.
- **R:** ggplot2, patchwork.
